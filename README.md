### Projet phare

**[Baromètre de la souveraineté numérique des communes romandes](https://github.com/YounoussAthie/barometre-souverainete-communes)**

Où les 661 communes de Suisse romande hébergent-elles leur messagerie ? À partir des seules données publiques (OFS, Wikidata, enregistrements DNS), le projet montre que **53,9 %** des communes passent par Microsoft 365 ou Google, avec de forts écarts entre cantons : de 0 % à Neuchâtel à 70,6 % à Fribourg. Jeu de données ouvert, documenté en DCAT-AP et reproductible.

`Python` `SPARQL` `DNS` `Open data` `DCAT-AP` `nLPD`
